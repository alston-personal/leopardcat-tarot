# 🎴 石虎塔羅 (LeopardCat Tarot) - A4 家用 DIY 列印指南

本文件說明如何使用石虎塔羅全套 78 張卡牌的 A4 DIY 拼版 PDF，在家用或超商/影印店印製標準尺寸（70mm x 120mm）的實體塔羅牌。

## ⚙️ 列印設定關鍵技巧（必讀）

為了確保列印後的卡牌維持標準尺寸（70mm x 120mm）且正背面精準對齊，列印時請嚴格遵守以下設定：

1. **尺寸與縮放 (Scale)**：
   - **務必選擇「實際大小 (Actual Size)」或「100%」**。
   - ⚠️ **切勿選擇「符合紙張大小 (Fit to Printable Area)」**，否則印表機自動縮放會破壞 70x120mm 幾何比例並導致雙面對齊偏移。
2. **雙面列印模式 (Two-Sided / Duplex)**：
   - 設定為**「長邊翻轉 (Flip on Long Edge)」**。
   - 拼版已精算水平置中對稱，長邊翻轉後正背面卡牌位置 100% 吻合。
3. **紙張建議 (Paper Weight & Type)**：
   - **試印 / 練習**：一般 A4 影印紙 (70~80gsm) 即可，裁切後可放入卡套 (Card Sleeves)。
   - **標準手感 (推薦)**：**250gsm ~ 350gsm** 銅西卡、雪銅紙、或頂級象牙卡（厚度適中且具備良好挺度與手感）。
   - **加強防護**：印製後可先行護膜 (Lamination) 或冷裱霧膜再進行裁切。

## ✂️ 手工裁切步驟

1. **準備工具**：
   - 銳利的美工刀或筆刀（建議 30 度美工刀）。
   - 金屬鐵尺（附防滑膠底更佳）。
   - 切割墊板。
2. **對準外圍裁切十字標記 (Crop Marks)**：
   - 每一頁的四邊天、地、左、右皆有延伸的裁切十字標記。
   - 將鐵尺平壓於對應的十字線兩端，一刀切通。
   - **技巧**：切紙時請勿一次切斷紙張邊緣的標記，保留紙張外框錨點，可讓後續刀刀精準。
3. **修圓角 (可選)**：
   - 推薦使用 **R3 或 R5 圓角器 (Corner Rounder Punch)** 修整卡牌四角，修角後即具備市售塔羅牌的圓潤質感與耐磨度。
